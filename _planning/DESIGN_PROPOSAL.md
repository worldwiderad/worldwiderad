## Where the identity comes from

Nothing below starts from portfolio conventions. Each decision points back to something Radek made.

- **Typeface: Petrona.** Both John Locke essays are set in Petrona (checked from the PDF font tables). The site uses the same face, so clicking from the homepage into an essay PDF feels like the same document. Petrona has true small caps, old-style and tabular figures, and superior numerals. Labels, tables and note numbers can be set the way a typesetter would set them, instead of with the tracked-uppercase sans labels that generated sites use.
- **Figure: the essay's own data.** In place of decoration, the first screen carries Figure 3 of *Should we be polite to ChatGPT?*: the lead of the polite over the bare prompt for each of the 25 tasks, transcribed from the published table. It shows the essay's actual claim, that the effect reverses by task type, in one glance.
- **Structure: an index of work, each entry with a status.** The essays qualify every claim ("an illustrative pilot, not a confirmatory test"). The site does the same in plain italic: *design under review*, *result 3 October*, *opens 19 November*, *prototype*. Unfinished work is labelled unfinished by the layout itself.
- **Colour: black on white.** That is what the essays, the tables and an orchestral score look like. There is no accent colour and no gradient, and the page prints as it looks.
- **Voice: first person, numbers first, quotes from the essays** where the essays already say it better.
